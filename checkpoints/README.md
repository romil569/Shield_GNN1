# Checkpoints

This release includes only the final small Elliptic++ Train200K checkpoints needed for reproducibility:

- `baseline_gcn_ellipticpp_train200k_100ep_best.pt`
- `baseline_graphsage_ellipticpp_train200k_100ep_best.pt`
- `shield_clean_ellipticpp_train200k_100ep_memsafe_best.pt`
- `shield_attack_defense_ellipticpp_train200k_100ep_memsafe_best.pt`

Each copied checkpoint is below GitHub's 100 MB hard file limit. Older exploratory checkpoints and full-Elliptic checkpoints are intentionally excluded.
